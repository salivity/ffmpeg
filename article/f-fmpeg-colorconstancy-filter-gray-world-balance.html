FFmpeg Colorconstancy Filter: Gray-World Balance

This article explains how to remove unwanted color casts from video using the colorconstancy filter in FFmpeg. By implementing the Gray-World assumption algorithm, FFmpeg can automatically estimate the scene's illuminant and shift colors back toward neutrality. Below, you will find the fundamental principles behind the algorithm, the required parameter settings, and practical command-line examples for processing your media.

Understanding Gray-World in FFmpeg

The Gray-World algorithm assumes that the average surface reflectance in a typical scene is neutral gray. If the overall average color of the frame deviates from gray, the algorithm attributes this shift to the light source (illuminant) and applies a correction to neutralize the cast.

In FFmpeg, the colorconstancy filter implements the framework developed by J. van de Weijer et al., which unifies algorithms like Gray-World, White-Patch, and Shades-of-Gray using two primary mathematical variables:

  • difford (Differentiation Order): Determines the order of spatial derivatives used. For classic intensity-based Gray-World, this must be set to 0.
  • minknorm (Minkowski Norm): Determines how pixel intensities are pooled. Classic Gray-World averages pixel values using an \(L_1\) norm, meaning this must be set to 1.

Basic Gray-World Command

To apply the standard Gray-World color balance to a video, use the filter graph -vf with difford=0 and minknorm=1:

ffmpeg -i input.mp4 -vf "colorconstancy=difford=0:minknorm=1" -c:a copy output.mp4

Key Parameters and Fine-Tuning

While the default Gray-World settings work well on balanced scenes, noisy or uneven footage may require parameter adjustments:

  • sigma: Sets the Gaussian smoothing scale (standard deviation). A small amount of smoothing (such as sigma=1 to sigma=3) prevents sensor noise or high-frequency artifacts from skewing the color estimate.
  • minknorm: While 1 gives strict Gray-World balance, values between 4 and 6 shift the algorithm toward the "Shades-of-Gray" method, which often produces more natural skin tones by giving higher weights to brighter pixels.

Example with Gaussian Smoothing

To eliminate color casts while smoothing out video noise:

ffmpeg -i input.mp4 -vf "colorconstancy=difford=0:minknorm=1:sigma=1.5" -c:a copy output.mp4

Example using Shades-of-Gray Variation

If strict Gray-World overcompensates in scenes dominated by a single saturated color (such as green grass or blue skies), increase the Minkowski norm:

ffmpeg -i input.mp4 -vf "colorconstancy=difford=0:minknorm=6:sigma=1" -c:a copy output.mp4
