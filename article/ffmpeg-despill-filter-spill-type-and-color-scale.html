FFmpeg Despill Filter: Spill Type and Color Scale

This guide explains how to properly configure the despill filter in FFmpeg to eliminate green or blue light contamination on chroma key subjects. By adjusting the spill type and the color scaling parameters, you can clean up color bleed along edges and semi-transparent regions without washing out the natural tones of your foreground video.

Understanding the Despill Parameters

The despill filter targets the reflected color cast caused by green or blue screens. The two key options for controlling which color is removed and how aggressively it is processed are type and scale.

  • type (or t): Defines the color of the screen used. Available values are green (default) or blue.
  • scale (or s): Sets the despill scaling factor. It determines how aggressively the dominant green or blue channel is dampened relative to the other color channels. Higher positive values remove more spill, while lower or negative values reduce the filter's strength.

Configuring Spill Type

To specify the color cast you need to neutralize, assign the type parameter directly in your video filter (-vf) graph.

For green screens:

ffmpeg -i input.mp4 -vf "despill=type=green" -c:a copy output.mp4

For blue screens:

ffmpeg -i input.mp4 -vf "despill=type=blue" -c:a copy output.mp4

Configuring Color Scale

By default, the scale parameter is set to 0.0. To adjust the strength of the suppression, supply a floating-point value. Increasing the scale pulls more of the target color out of the affected pixels, while decreasing it prevents unwanted color loss in areas that naturally contain the target color (such as green clothing or blue eyes).

To apply an aggressive despill on a green screen:

ffmpeg -i input.mp4 -vf "despill=type=green:scale=0.5" -c:a copy output.mp4

To apply a subtle correction:

ffmpeg -i input.mp4 -vf "despill=type=green:scale=-0.2" -c:a copy output.mp4

Channel-Specific Color Scale Adjustments

If adjusting the overall scale shifts the color balance of your subject too drastically, you can scale individual color channels using red (r), green (g), or blue (b). These settings scale the corresponding channel's contribution when computing the despill target:

ffmpeg -i input.mp4 -vf "despill=type=green:scale=0.1:red=0.2:blue=-0.1" -c:a copy output.mp4

Chaining with Chroma Keying

In a complete chroma key workflow, the despill filter should be applied after the chromakey filter or colorkey filter. This ensures the transparent alpha channel is created before remaining spill reflections are corrected.

ffmpeg -i foreground.mp4 -i background.mp4 -filter_complex \
"[0:v]chromakey=0x00FF00:0.1:0.05,despill=type=green:scale=0.2[fg]; \
 [1:v][fg]overlay=shortest=1[outv]" \
-map "[outv]" -map 0:a? -c:v libx264 -c:a copy output.mp4
