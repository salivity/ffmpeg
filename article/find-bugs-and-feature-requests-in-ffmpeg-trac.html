Find Bugs and Feature Requests in FFmpeg Trac

Navigating the FFmpeg Trac issue tracker allows developers and users to track ongoing software issues, monitor feature proposals, and contribute to discussions. This guide outlines how to access the FFmpeg Trac system, use pre-built reports, filter for active defects, and query open feature requests efficiently.

Accessing the Ticket System

Navigate to the official FFmpeg Trac system via your web browser. From the main page, the primary interface for inspecting tickets is located in the top navigation bar under the View Tickets tab.

Viewing Pre-Defined Reports

The simplest way to browse existing issues is by using the default reports provided by Trac:

  1. Click on View Tickets in the main navigation menu.
  2. Select a pre-configured report from the list:
    • Active Tickets: Displays all open tickets across all categories.
    • Active Tickets by Component: Groups open tickets based on FFmpeg components (e.g., ffmpeg, ffprobe, avcodec, avformat).
  3. Sort the results dynamically by clicking on any column header, such as Priority, Component, or Created.

Filtering for Active Bug Reports Using Custom Query

To isolate active bug reports specifically, use the Custom Query feature:

  1. Go to the View Tickets page and click Custom Query (or the search/filter button).
  2. Set the filters to match active defects:
    • Type: Select defect.
    • Status: Check new, open, and reopened (ensure closed is unchecked).
    • Resolution: Leave empty or exclude fixed, invalid, duplicate, and wontfix.
  3. Select any additional fields you want to view, such as Version, Milestone, or Summary.
  4. Click Update to generate the list of unresolved bug reports.

Finding Active Feature Requests

Feature requests in Trac are categorized as enhancements rather than bugs. To query active feature requests:

  1. Open the Custom Query interface.
  2. Adjust the search parameters:
    • Type: Select enhancement.
    • Status: Ensure only new, open, or reopened are selected.
  3. Click Update to view all proposed features that have not yet been implemented or resolved.

Searching by Keywords

If you are looking for specific issues (such as a particular codec or hardware acceleration method):

  1. Use the Search box located in the top-right corner of the Trac interface.
  2. Enter your keyword (for example, hevc, vaapi, or subtitles).
  3. Filter the search results on the results page by checking only the Tickets box to exclude wiki pages and changesets from your search.
