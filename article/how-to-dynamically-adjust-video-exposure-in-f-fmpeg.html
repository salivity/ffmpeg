How to Dynamically Adjust Video Exposure in FFmpeg

This article explains how to dynamically adjust and correct video exposure in FFmpeg using built-in video filters. It covers automatic frame-by-frame lighting normalization with temporal smoothing, time-based exposure animations using mathematical expressions, targeted exposure value (EV) adjustments across specific timestamps, and luminance smoothing for flickering footage.

Automatic Exposure Balancing with the Normalize Filter

When dealing with video footage that moves between bright and dark environments, a static exposure adjustment will either blow out the highlights or crush the shadows. The normalize filter solves this by analyzing the color and luminance histogram of every frame and stretching it to fill the full dynamic range.

By adding the smoothing parameter, FFmpeg calculates a rolling average across multiple frames. This mimics the smooth auto-exposure behavior of a physical camera sensor rather than causing abrupt frame-to-frame brightness jumps.

ffmpeg -i input.mp4 -vf "normalize=blackpt=black:whitept=white:smoothing=50:independence=0" -c:a copy output.mp4

Key parameters for the normalize filter include:

  • blackpt and whitept: Define the output colors to which the darkest and brightest input pixels are mapped. Setting these to black and white maximizes the dynamic range.
  • smoothing: Controls the number of previous frames used for temporal smoothing. A value between 30 and 60 generally provides a natural transition across changing lighting conditions.
  • independence: Controls the ratio of independent channel stretching versus linked luminance stretching. Setting this to 0.0 preserves the original color cast while only adjusting overall exposure, whereas 1.0 normalizes red, green, and blue channels independently (which also performs automatic white balance).
  • strength: Limits the overall intensity of the filter on a scale from 0.0 to 1.0. If full normalization looks artificial, setting strength=0.7 blends the normalized result with the original exposure.

Adjusting Exposure Values Over Specific Time Ranges

If your video only suffers from poor exposure during specific segments, you can use the dedicated exposure filter paired with FFmpeg timeline editing. Unlike basic brightness filters that simply add a constant offset to all pixels, the exposure filter operates in photographic Exposure Value (EV) stops.

Using the enable option, you can activate the exposure correction only during designated timestamps:

ffmpeg -i input.mp4 -vf "exposure=exposure=1.2:black=-0.02:enable='between(t,10,25)'" -c:a copy output.mp4

How the parameters work in this command:

  • exposure: Adjusts the exposure correction in EV stops, ranging from -3.0 to 3.0. A positive value brightens the image, while a negative value darkens it.
  • black: Sets the black level correction from -1.0 to 1.0, helping recover shadow detail or prevent washed-out blacks when boosting exposure.
  • enable='between(t,10,25)': Instructs FFmpeg to apply the filter only between the 10-second and 25-second marks of the video.

If you need multiple exposure adjustments across different scenes in a single pass, you can chain multiple exposure filters together or pass timestamped commands using the sendcmd filter:

ffmpeg -i input.mp4 -vf "sendcmd=c='0.0 exposure exposure 0.0; 10.0 exposure exposure 1.5; 25.0 exposure exposure -0.5',exposure" -c:a copy output.mp4

Programmatic Exposure Ramping with Frame Expressions

When a video transitions gradually from a dark room to a bright outdoor scene, an instant exposure toggle at a specific timestamp will look jarring. To create a smooth, gradual ramp in exposure, use the eq (equalizer) filter with frame-level evaluation enabled.

The eq filter accepts mathematical expressions containing the variable t (time in seconds) or n (frame number) when eval=frame is specified.

ffmpeg -i input.mp4 -vf "eq=brightness='if(between(t,5,10), (t-5)*0.04, if(gt(t,10), 0.2, 0))':eval=frame" -c:a copy output.mp4

In this command:

  1. Before 5 seconds, the brightness offset remains at 0.
  2. Between 5 and 10 seconds, (t-5)*0.04 linearly ramps the brightness from 0.0 up to 0.2.
  3. After 10 seconds, gt(t,10) holds the brightness steady at 0.2 for the remainder of the video.
  4. eval=frame forces FFmpeg to recalculate the brightness equation on every single frame rather than only once at the start of the stream.

You can apply the same dynamic expression logic to the gamma parameter inside the eq filter, which often yields more natural midtone exposure adjustments than linear brightness shifts:

ffmpeg -i input.mp4 -vf "eq=gamma='if(between(t,5,10), 1+(t-5)*0.1, 1)':eval=frame" -c:a copy output.mp4

Smoothing Erratic Exposure Shifts with Deflicker

Time-lapse videos, older film transfers, and footage recorded under artificial lighting often suffer from rapid micro-fluctuations in exposure. The deflicker filter dynamically adjusts frame luminance by calculating an average brightness across a moving window of frames.

ffmpeg -i input.mp4 -vf "deflicker=size=15:mode=pm" -c:a copy output.mp4

Key configuration options for deflicker:

  • size: Sets the number of frames in the moving average window (from 2 to 129). Smaller values (5 to 15) remove high-frequency flicker without affecting intentional lighting transitions, while larger values (30 or more) smooth out slower auto-exposure stepping.
  • mode: Determines the averaging algorithm used to calculate the target luminance. Common modes include am (arithmetic mean), gm (geometric mean), pm (power mean), and median.

Dynamic Contrast and Exposure Recovery with Histogram Equalization

For footage with severe uneven exposure where both deep shadows and bright highlights exist simultaneously across changing scenes, the histeq filter performs global histogram equalization on a per-frame basis. It redistributes pixel intensities dynamically so that tonal details remain visible regardless of sudden lighting shifts.

ffmpeg -i input.mp4 -vf "histeq=strength=0.15:intensity=0.20:antibanding=strong" -c:a copy output.mp4
  • strength: Determines the amount of equalization to apply, from 0.0 to 1.0. Keeping this value low (0.1 to 0.25) prevents unnatural contrast distortion.
  • intensity: Sets the maximum intensity that can be generated and scales the output values appropriately.
  • antibanding: Adds controlled random noise (none, weak, or strong) to prevent visible color banding in smooth gradients like skies or walls when stretching underexposed regions.
