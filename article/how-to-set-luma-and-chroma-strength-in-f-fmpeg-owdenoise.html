How to Set Luma and Chroma Strength in FFmpeg owdenoise

This guide explains how to control luma and chroma noise reduction using the owdenoise (Overcomplete Wavelet Denoiser) filter in FFmpeg. You will learn the exact parameter syntax for both brightness and color planes, their default behaviors, recommended value ranges, and practical command-line examples to reduce noise without over-softening your video.

Understanding owdenoise Strength Parameters

The owdenoise filter reduces noise by breaking down video frames into wavelet components. It provides independent controls for the brightness (luma) and color (chroma) channels using the following parameters:

  • luma_strength (alias ls): Sets the denoising intensity for the luma (\(Y\)) plane. The value is a double-precision float ranging from 0.0 to 1000.0. The default value is 1.0.
  • chroma_strength (alias cs): Sets the denoising intensity for the chroma (\(U\) and \(V\)) planes. The value is a double-precision float ranging from 0.0 to 1000.0. The default value is 1.0.

Setting either value to 0 disables denoising for that specific plane. Increasing the values results in stronger smoothing, but excessively high values will blur fine details and cause watercolor-like artifacts.

Basic Syntax

To apply the filter with custom strengths, use the -vf (video filter) option:

ffmpeg -i input.mp4 -vf "owdenoise=ls=1.5:cs=1.0" -c:a copy output.mp4

You can also use the full parameter names interchangeably:

ffmpeg -i input.mp4 -vf "owdenoise=luma_strength=1.5:chroma_strength=1.0" -c:a copy output.mp4

Common Configuration Scenarios

1. Moderate Balanced Denoising

For footage with mild high-ISO grain across both color and brightness:

ffmpeg -i input.mp4 -vf "owdenoise=ls=1.2:cs=1.2" -c:v libx264 -crf 18 -c:a copy output.mp4

2. Removing Chroma (Color) Noise Only

Digital camera sensors often produce colored speckles in low light while the underlying image details remain sharp. To target color noise without blurring edge details on the luma plane, set ls to 0:

ffmpeg -i input.mp4 -vf "owdenoise=ls=0:cs=2.5" -c:v libx264 -crf 18 -c:a copy output.mp4

3. Heavy Denoising with Wavelet Depth Adjustment

The owdenoise filter also includes a depth parameter (ranging from 8 to 16, default 8) that controls the number of decomposition levels. Higher depth values allow the filter to target coarser noise patterns alongside the strength parameters:

ffmpeg -i input.mp4 -vf "owdenoise=depth=10:ls=3.0:cs=2.5" -c:v libx264 -crf 18 -c:a copy output.mp4

Tuning Recommendations

  • Values between 0.5 and 2.0: Best for general preservation of sharp lines and micro-textures.
  • Values between 2.0 and 5.0: Suitable for heavily degraded, grainy, or low-light video clips.
  • Values above 5.0: Rarely needed and usually result in severe loss of detail.
