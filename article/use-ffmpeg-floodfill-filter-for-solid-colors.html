Use FFmpeg Floodfill Filter for Solid Colors

This guide explains how to use the FFmpeg floodfill filter to target a specific area of a video and fill it with a uniform, solid color. You will learn the essential syntax, understand how seed points and color components work, and review clear command-line examples to modify bounded or matching color regions in your video streams.

Understanding the Floodfill Filter Syntax

The floodfill filter operates like the "paint bucket" tool found in graphic design software. It begins at a starting coordinate (a seed point) and replaces matching adjacent pixels with a replacement color.

The basic syntax is:

ffmpeg -i input.mp4 -vf "floodfill=x=VALUE:y=VALUE:d0=VAL:d1=VAL:d2=VAL" output.mp4

Key Parameters

  • x: The horizontal starting position (pixel column) of the seed point.
  • y: The vertical starting position (pixel row) of the seed point.
  • s0, s1, s2, s3: The source color component values to be replaced. If omitted, FFmpeg automatically samples the color of the pixel located directly at (x, y).
  • d0, d1, d2, d3: The destination/replacement color component values for planes 0, 1, 2, and 3.

Color Spaces and Component Values

FFmpeg processes color values based on the pixel format of the video:

  • RGB formats (e.g., rgb24, gbrp): The values represent color intensities ranging from 0 to 255. In gbrp or standard RGB processing, plane 0, 1, and 2 map to the red, green, and blue channels (or green, blue, red depending on the planar structure).
  • YUV formats (e.g., yuv420p):
    • d0 represents Luma (Y), ranging from 16 to 235 (or 0 to 255 in full range).
    • d1 represents Chroma Blue (U), centered at 128.
    • d2 represents Chroma Red (V), centered at 128.

Converting your video to an RGB format inside the filter chain makes setting solid colors more intuitive.

Practical Examples

1. Auto-Detecting the Source Color and Filling with Pure Red

To fill the area starting at coordinate x=320, y=240 with solid red, convert to an RGB format, apply the filter, and convert back to a standard playback format:

ffmpeg -i input.mp4 -vf "format=rgb24,floodfill=x=320:y=240:d0=255:d1=0:d2=0,format=yuv420p" -c:a copy output.mp4

In this command:

  • format=rgb24 ensures predictable 8-bit RGB channels.
  • x=320:y=240 sets the fill origin.
  • FFmpeg automatically samples the color at (320, 240) to determine what color to replace.
  • d0=255:d1=0:d2=0 applies solid red (R=255, G=0, B=0).
  • format=yuv420p returns the video to a universally compatible format.

2. Specifying Both Source and Target Colors

If you want the fill operation to trigger only if the seed point matches a specific color (for example, replacing pure white with solid black), explicitly set the source parameters (s0, s1, s2):

ffmpeg -i input.mp4 -vf "format=rgb24,floodfill=x=100:y=100:s0=255:s1=255:s2=255:d0=0:d1=0:d2=0,format=yuv420p" -c:a copy output.mp4

If the pixel at (100, 100) does not match (255, 255, 255), the filter leaves the frame untouched.

3. Using Native YUV Values (Solid Black)

To avoid color space conversions, compute the native YUV values. For solid black in limited-range YUV:

  • Y (d0) = 16
  • U (d1) = 128
  • V (d2) = 128
ffmpeg -i input.mp4 -vf "floodfill=x=50:y=50:d0=16:d1=128:d2=128" -c:a copy output.mp4

Best Practices

  • Bounded Areas: The fill expands continuously until it encounters pixels that differ from the source color. Ensure high-contrast or distinct boundaries so the color does not bleed across unwanted areas.
  • Coordinate Accuracy: Use a media player or image editor to confirm the exact (x, y) coordinate of the area you intend to fill before running the command on an entire video.
